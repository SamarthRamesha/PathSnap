Everyone should run `./start_demo.sh`, follow one request on trip 00000052 from the browser to the API log, and read the model, decoder, and scoring sequence in the README. Learn to explain an observation, a candidate arc, a path segment and a post-prediction reference before memorising metrics.

Use the same explanations for the score panel. **Matched observations** counts returned GPS-row matches. **Point reference agreement** compares each match to the nearest arc on the reference route, with missing matches contributing no agreement. **Route arc F1** combines precision and recall on unique directed arc IDs and includes intermediate arcs. The two metrics answer different questions. The 96.2% and 68.9% values come from the recorded live run of one held-out trip.
